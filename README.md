# Fedora KDE Cloud PC on GitHub Codespaces

Run a full **Fedora 40 KDE Plasma** workstation directly inside your web browser using GitHub Codespaces.

## Features
- **OS:** Fedora 40
- **Desktop Environment:** KDE Plasma (X11) + Dolphin + Konsole
- **Web Browser:** Pre-installed Firefox
- **Remote Access:** High-performance TigerVNC streamed directly to your browser via noVNC (Port 6080)
- **VNC Password:** `fedora123`

## How to Launch with Highest Power

1. Click the green **Code** button at the top of this repository.
2. Select the **Codespaces** tab.
3. Click the **three dots (`...`)** next to Codespaces and select **New with options**.
4. In the **Machine type** dropdown, select **4 cores, 16 GB RAM, 32 GB storage** (`standardLinux32gb`).
5. Click **Create codespace**.
6. When the Codespace finishes initializing, it will automatically open the forwarded port **6080**.
7. Enter the VNC password: `fedora123`
8. Enjoy your Fedora KDE Cloud PC!
